Password and recovery token

Use the password chosen during installation. To set or change it, run:

docker compose exec hub solarman-hub password --data-dir /data

Restart the Hub after changing the password. The recovery token also works:

Read it locally on the server:

docker compose exec hub solarman-hub token --data-dir /data

When running without Docker: solarman-hub token --data-dir ./data. The token is never sent to the logger or cloud.

APPLICATION SETTINGS

Server and listeners

Ports and addresses require restart

In Docker, keep the bind address at 0.0.0.0. Give the logger the host IP and published port.

Cloud forwarding

When the cloud is unavailable, known frames receive local ACKs. Outage reports stay local; cloud history backfill is not supported.

Home Assistant and MQTT

No Home Assistant API token is needed. The app connects to the broker; HA receives data through its MQTT integration.

Files and retention

Measurement history

The first age or size limit reached removes the oldest history. Raw frames and JSONL have separate rotation limits.

Data is stored in the persistent volume /data/archive. Disk-full errors are visible; cloud forwarding continues.

Loggers

Explicitly choose which devices may connect.

The serial identifies the logger, not the inverter. An empty allowed IP accepts any address for that serial. “Forward only” skips decoding.

DECODE WITHOUT CHANGING TRANSPORT
