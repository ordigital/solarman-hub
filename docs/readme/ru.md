# Solarman Hub

![Solarman Hub](../images/solarman-hub.png)

**Solarman Hub — независимый любительский проект. Он не связан с SOFAR (SofarSolar).**

[English](../../README.md) · [Polski](pl.md) · [Deutsch](de.md) · [Français](fr.md) · [Čeština](cs.md) · [Slovenčina](sk.md) · [Lietuvių](lt.md) · [Українська](uk.md) · [Русский](ru.md)

Solarman Hub подключает ваш логгер Solarman V5 к облаку производителя и одновременно предоставляет измерения локально. В веб-панели можно просматривать текущие показания и графики, хранить историю, управлять профилями декодирования и подключить Home Assistant через MQTT. Панель и руководство доступны на девяти языках.

Встроенный профиль Sofar HYD G3 / LSW3 декодирует 48 полей измерений. Другим форматам нужен совместимый, независимо проверенный профиль. Пересылка продолжается, даже если отчёт невозможно декодировать.

## Выберите способ установки

| Среда | С чего начать |
|---|---|
| Linux с Docker Engine и Compose v2 | Быстрый старт ниже |
| Proxmox VE | [Пошаговое руководство: VM Debian 13 + Docker](../proxmox/ru.md) |
| Python 3.12+ без Docker | [Руководство пользователя](../../src/solarman_hub/guides/ru.md) |

Для Proxmox начните с VM Debian 13, 2 vCPU, 2 GB RAM и диска 20 GB. Зарезервируйте её адрес LAN и включите автоматический запуск. Для более длинной истории выделите больше места на диске.

[Изменение сервера логгера: пошаговая инструкция, включая скрытую страницу настроек.](../../src/solarman_hub/guides/ru.md)

**[Автоматическая установка VM](../proxmox/ru.md)**

Выполните эту команду как **root в Shell узла Proxmox**, а не внутри VM. Мастер проведёт вас по шагам. Перед подтверждением проверьте сводку.

```sh
bash -c "$(wget -qLO - https://raw.githubusercontent.com/ordigital/solarman-hub/main/scripts/proxmox-vm.sh)"
```

## Быстрый старт с Docker

Если Docker Engine и Compose v2 уже установлены:

```sh
git clone https://github.com/ordigital/solarman-hub.git
cd solarman-hub
docker compose up -d --build --wait --wait-timeout 120
docker compose exec hub solarman-hub token --data-dir /data
```

Запускайте команды Docker с достаточными правами, добавляя `sudo`, если этого требует ваша установка.

Откройте `http://SERVER_IP:8080`, используя IP хоста Docker или VM. Войдите с показанным токеном, добавьте числовой **серийный номер логгера**, выберите профиль, сохраните и примените. Затем направьте удалённый TCP-адрес логгера на тот же IP хоста и порт `10000`. Новые установки не принимают неизвестные логгеры. Адрес VM отличается от адреса управления Proxmox. Токен не меняется после перезапуска или обновления, пока сохраняется том данных.

Конфигурация, токены и история сохраняются в томе Docker, смонтированном в `/data`. Учётная запись Solarman, cookies и пароль Wi-Fi не нужны. MQTT использует адрес и учётные данные вашего брокера, а не токен API Home Assistant.

Инструкции для собственных портов и существующих установок, созданных через `docker run`, приведены в руководстве.

## Необязательный ESP32 Companion

[Исходники](../../firmware/esp32-companion) · [Прошивка USB/OTA и контрольные суммы](../../firmware/esp32-companion/dist)

Companion может принимать и пересылать отчёты V5, захватывать трафик Wi-Fi и экспортировать профили декодирования. Он работает на классическом ESP32 с 4 MB flash и имеет англоязычный интерфейс. ESP32 необязателен: Hub работает без него.

Откройте **ESP32 / Прошивка** в Hub, чтобы скачать прошивку и найти инструкции USB/OTA. Заводская прошивка может сбросить настройки платы. В Proxmox сначала передайте USB-устройство платы в VM.

Профили, созданные из неизвестных отчётов, нужно проверить вручную. Companion не может определить электрические измерения по произвольным байтам или автоматически расшифровать трафик Wi-Fi.
